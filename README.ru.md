# Nokori

**[English](README.md) · [繁體中文](README.zh-Hant.md)**<br>
[简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md)

Нативный монитор использования ИИ для macOS: питомец-солнце в центре круглой или растекающейся стеклянной панели.

> Независимая версия [Pulse от qunqin24](https://github.com/qunqin24/Pulse), не одобренная автором оригинала. Выбрано имя **Nokori (ранее Pulse Pet)** для этой независимой версии.

## Что изменено

- **Pet orb:** прежний круг сохранён; питомец остаётся в центре и при сворачивании, и при раскрытии.
- **Liquid pet:** слегка растёкшийся неровный контур. При перетаскивании появляется отстающий хвост, после отпускания форма успокаивается. Это визуальное приближение поверхностного натяжения и вязкости, а не симуляция жидкости. «Уменьшение движения» отключает растяжение и отдачу.
- **Classic rail:** исходная панель у края экрана также доступна.
- При приближении указателя раскрываются кольца аккаунтов; наведение на кольцо открывает прежнюю карточку. Уход с панели и карточки сворачивает панель.
- По умолчанию — анимированное Little sun. Можно выбрать кота, лису, кролика или прозрачный PNG и изменить размер.
- Дополнительные [питомцы по погоде](Docs/weather-pet.md): облака, дождь, гроза, снег, туман и луна. Фиксированные изображения доступны без сети. Для местной погоды можно явно разрешить геопозицию или выбрать город вручную, в том числе при отказе в доступе. Бесплатный сервис Open-Meteo предназначен только для некоммерческого использования.
- Сохранены данные провайдеров, аккаунты, история, строка меню, уведомления и интеграции. [Все функции](Docs/features.md) · [Сервисы](Docs/supported-services.md).
- Пороги предупреждения 75%, 80%, 90%, 95% дополнены произвольным значением **1–100%**.

## Установка и настройки

**[Скачать пробный DMG — Apple Silicon＋Intel](Downloads/Nokori-1.12.6-weather-exclusive-58c8a96-trial-universal.dmg?raw=true)** · [SHA-256 и границы проверки](Downloads/README.md). Файл размещён прямо в репозитории; это не стабильная версия и не GitHub Release с тегом. Первый запрос разрешения на геолокацию и успешное определение местоположения ещё не проверены. В сборках исходного Pulse этих изменений нет.

1. Откройте DMG и перенесите **Nokori.app** в «Программы», не заменяя исходный **Pulse.app**.
2. Настройки, данные, объект входа и URL-схема независимы. Настройки оригинала не переносятся, обновления из исходного проекта отключены.
3. Выберите сервисы после запуска. Приложение работает в строке меню; настройки доступны и через правую кнопку на панели.
4. Пробная сборка имеет только ad-hoc подпись и **не нотарифицирована Apple**. Только для доверенного файла используйте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Требуется macOS 14+, для полного Liquid Glass — macOS 26+. Universal-сборка предназначена для Apple Silicon и Intel; новые панели не проверены на реальном Intel и старых macOS.

Оба приложения могут пользоваться одним аккаунтом провайдера, CLI-входом или связкой ключей. Раздельные данные не означают отдельную квоту сервиса. Общую интеграцию status line Claude Code включайте только в одном приложении.

- **Настройки → Оформление → Стиль панели:** Pet orb / Liquid pet / Classic rail.
- **Настройки → Основные → Язык интерфейса:** английский, традиционный/упрощённый китайский, японский, корейский, русский или системный. Ссылки вверху переключают только README.
- **Настройки → Уведомления:** выберите или введите порог, примените и разрешите уведомления macOS. Оповещения основаны на полученных показаниях, а не непрерывном наблюдении.

> **Обновление с Pulse Pet:** завершите старую версию, установите Nokori и удалите только старое приложение Pulse Pet, не его данные. Прежний независимый идентификатор настроек и данных сохранён. Не запускайте обе версии под разными именами одновременно. Исходный Pulse может работать вместе с Nokori. [Бренд и совместимость](Docs/branding.md).

## Источник погоды и стоимость

Автоматическая погода использует **Open-Meteo, а не данные из приложения Apple «Погода» или WeatherKit**. По умолчанию функция выключена. Если она включена и плавающая панель видна, данные обновляются примерно раз в 30 минут, а не синхронно в реальном времени. Бесплатный API не требует ключа, но разрешён **только для некоммерческого использования**, имеет ограничения числа запросов и не гарантирует доступность сервиса. Разрешение геолокации даёт доступ только к местоположению, а не к приложению «Погода»; общая квота разработчика WeatherKit сейчас не расходуется. [Подробнее об источнике, стоимости и конфиденциальности (на английском)](Docs/weather-pet.md#data-source-and-cost).

## Сборка из исходников

Нужны полный Xcode, SDK macOS 26 или новее, Swift tools 6.0+ и Python 3. Не удаляйте превью и не используйте только Command Line Tools.

```bash
git clone https://github.com/wenyen-hsu/Pulse.git Nokori
cd Nokori
swift build
TZ=UTC swift test
./Scripts/check-localization.sh
./Scripts/bundle.sh --zip
./Scripts/dmg.sh
```

Результат: `build.noindex/Nokori.app`, `Nokori-<version>.zip` и `Nokori-<version>.dmg`. Локальная упаковка не создаёт публичный релиз. [Инструменты](Docs/build-from-source.md) · [Упаковка](Docs/releasing.md).
