# 天氣寵物

**[English](weather-pet.md) · 繁體中文** · [試用下載與驗證範圍](../Downloads/README.md)

## 目前使用哪個天氣來源？

Nokori 目前向 **[Open-Meteo](https://open-meteo.com/)** 查詢天氣與城市，**不是讀取 Apple「天氣」App，也沒有使用 WeatherKit**，不會取得「天氣」App 儲存的城市或快取。

啟用自動天氣後，會將授權取得的約略位置，或手選城市的座標送給 Open-Meteo，依天氣代碼與日夜狀態切換晴天、月亮、多雲、陰天、雨、雷雨、雪或霧。這些是模型推算的目前天氣，不保證等同所在地測站觀測。啟用且浮點面板可見時約每 30 分鐘更新，**不是與 Apple「天氣」即時同步**。

內建的固定天氣寵物是本機繪製的圖案，可離線選擇；選到雨或雪，不代表當地正在下雨或下雪。程式的藍色玻璃太陽 icon 不會隨天氣改變。

## 免費嗎？會使用共用額度嗎？

- **目前不需 API Key。** Open-Meteo 免費 API 僅限非商業用途，需保留來源署名。免費下載不代表一定屬於非商業使用；商業產品、廣告、訂閱或商業推廣須另外確認適用方案。
- **免費不是無限流量。** 官方條款要求少於每日 10,000 次、每小時 5,000 次及每分鐘 600 次；免費方案表另列每月 300,000 次。限制依 IP 與應用程式套用，**不是每位使用者都保證各有一份額度**，同公司或共用網路也可能受限。服務可用性與準確性不保證；以[官方條款](https://open-meteo.com/en/terms)及[方案頁](https://open-meteo.com/en/pricing)為準。
- **目前沒有使用 Apple 開發者的 WeatherKit 額度。** 若未來改接 [WeatherKit](https://developer.apple.com/weatherkit/)，則需配置 Apple Developer Program 會員，內含的每月 50 萬次查詢是按開發者會員共用，不是每位使用者各有 50 萬次。此方案尚未實作，也不保證與「天氣」App 同時更新。
- **定位授權只提供位置。** 使用者同意定位，不等於授權讀取另一個 App，也不會因此免除天氣服務費用或限制。

程式保留 Apache 2.0 授權；這不會免除外部天氣 API 的條款。商業天氣部署需另選合適服務與認證設計，不能把共用私密金鑰放進公開程式。關閉自動天氣後，固定寵物、自訂 PNG 與用量監控仍可使用。

## 如何啟用與測試？

1. 到「設定 → 外觀 → 自動天氣寵物」啟用；**預設關閉，啟動時不會主動要求新定位授權**。
2. 若要自動定位，先確認 macOS「系統設定 → 隱私權與安全性 → 定位服務」已開啟，再選目前位置、按「允許定位」。若先前已授權，重新啟用時可直接定位，不會每次重問。
3. 拒絕、受限制或無法定位時，改選城市，輸入 `Taipei` 等名稱、按搜尋，再選取正確的城市／地區／國家結果；不會自動挑第一筆。
4. 確認設定顯示天氣與資料時間。首次讀取失敗會顯示中性雲朵與問號，不會假裝晴天；之後更新失敗則保留相同地點的上次讀值，標示過期。切換城市不會把舊城市天氣當成新城市結果。

自動天氣與手選寵物互斥：**啟用天氣時，固定寵物選單、匯入 PNG 與使用內建寵物按鈕都會停用**。原寵物、PNG 與大小設定會保留，天氣圖示暫時取代 PNG；即使暫時讀不到天氣，也不會改回 PNG。關閉自動天氣後恢復原寵物或圖片，大小與面板樣式仍可調整。

傳統側欄與隱藏面板會暫停天氣查詢，已儲存的 PNG 不會。暫停時仍可明確搜尋及選擇城市，稍後恢復面板再讀取天氣；定位按鈕會停用並顯示暫停狀態。

目前主要提供的 `58c8a96` 試用包已包含互斥控制，並使用新一輪原生桌面驗證通過的同一份程式打包，沒有重新編譯；見[下載說明與驗證範圍](../Downloads/README.md)。另保留的舊 `64e1028` 試用包仍使用 PNG 優先規則。

## 位置與隱私

- 只有按「允許定位」才會要求新的系統授權；取得一次位置，不持續追蹤。要求精度約三公里，送出前將座標四捨五入至小數點後兩位，並非保證三公里的誤差範圍。
- Open-Meteo 會收到天氣查詢的約略座標，或城市搜尋文字，以及連線 IP；**不附上服務商帳號、憑證、用量紀錄或裝置識別碼**。
- 所選城市及其座標、自動天氣開關與來源會儲存在 Nokori 的獨立設定；裝置定位結果與天氣讀值只保存在本機記憶體，不記錄位置歷史，重開程式後需重新連線取得天氣。
- 本機不儲存位置歷史，不代表遠端服務沒有紀錄。Open-Meteo 的[隱私政策](https://open-meteo.com/en/terms)說明，伺服器請求紀錄可能包含座標，並會在 90 天後刪除。
- 天氣與城市搜尋都遵守 App 的代理設定；「僅限系統代理」在系統沒有代理時會拒絕請求。使用不儲存 cookie 或憑證的連線，並拒絕重新導向。
